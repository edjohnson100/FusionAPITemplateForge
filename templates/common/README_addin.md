## Installation

This add-in requires a quick manual installation. You can install it in Fusion's default Add-Ins directory or a custom folder of your choice.

### Option 1: Install in the Default Fusion Directory

1. **Move the folder:** Move the entire `{{NAME}}` folder into your Fusion Add-Ins directory:
   * **Windows:** `%appdata%\Autodesk\Autodesk Fusion 360\API\Addins`
   * **Mac:** `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/Addins`
2. **Open Fusion:** Press `Shift + S` to open the **Scripts and Add-Ins** dialog.
3. **Run it:** Make sure the **Add-Ins** filter checkbox is checked. You should see `{{NAME}}` in the list. Check **Run on Startup** if you want it to load automatically, then click the **Run** icon.

### Option 2: Install in a Custom Directory

1. **Organize:** Keep the `{{NAME}}` folder wherever you like (e.g. a dedicated `Documents\Fusion_Tools` folder).
2. **Open Fusion:** Press `Shift + S` to open the **Scripts and Add-Ins** dialog.
3. **Add the add-in:** Click the **"+"** icon next to the search box at the top of the dialog and select **Script or add-in from device**.
4. **Locate:** Navigate to and select the `{{NAME}}` folder, then click **Select Folder**.
5. **Run it:** Make sure the **Add-Ins** filter checkbox is checked. You should see `{{NAME}}` in the list. Check **Run on Startup** if you want it to load automatically, then click the **Run** icon.
