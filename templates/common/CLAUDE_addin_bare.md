# CLAUDE.md

This is a Fusion 360 add-in (`{{NAME}}`), generated by Fusion API Template Forge (bare tier: a command definition, no persistent HTML palette).

There is no build system, package manager, or test suite -- this only runs inside Fusion 360's embedded Python interpreter via the Fusion 360 add-in loader. `adsk.core`/`adsk.fusion` only exist inside the Fusion 360 process.

## Running / testing changes

1. Open Fusion 360 -> Utilities -> Add-Ins -> Scripts and Add-Ins -> add this folder as an add-in.
2. Run/reload the add-in, then use its toolbar button (see `config.DEFAULT_PANEL_ID`) to exercise the change.
3. Use `futil.log(...)` (see `lib/fusionAddInUtils/general_utils.py`) to write to the Text Command window; toggle verbose logging via `config.DEBUG`.

## Architecture

- `{{NAME}}.py` is the entry point Fusion calls (`run()`/`stop()`), delegating to `commands.start()`/`commands.stop()`.
- `commands/__init__.py` is the registry of top-level commands.
- `commands/ExampleCommand.py` is a stub command -- replace `command_execute()` with your add-in's real behavior.
- `config.py` holds add-in-wide constants: `DEBUG`, `ADDIN_NAME` (folder-derived), `COMPANY_NAME`, workspace/panel IDs, and `ADDIN_VERSION` (read from the `.manifest` file -- never hardcode a version string elsewhere).
