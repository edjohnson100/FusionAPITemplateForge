## Installation

### Manual Installation Options

This [add-in/script] requires a quick manual installation. You can choose to install it in Fusion's default directory or a custom folder of your choice.

#### Option 1: Install in the Default Fusion Directory
1. **Download:** Download the source code as a ZIP file and extract the `[add-in/script name]-main` folder. Rename the folder to `[add-in/script name]` (remove the `-main` suffix) — Fusion requires the folder name to match the add-in name exactly, so it won't run correctly if you skip this step.
Download the zip file using the green `Code` button above or simply click this link: [[add-in/script name] Main Branch](https://github.com/edjohnson100/[add-in/script name]/archive/refs/heads/main.zip)
2. **Move the Folder:** Move the entire `[add-in/script name]` folder into your native Fusion Scripts directory:
   * **Windows:** `%appdata%\Autodesk\Autodesk Fusion 360\API\[Addins/Scripts]`
   * **Mac:** `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/[Addins/Scripts]`
3. **Open Fusion:** Press `Shift + S` to open the **Scripts and Add-Ins** dialog.
4. **Run the Script:** Make sure the **[Add-ins/Scripts]** filter checkbox is checked. You should see **[add-in/script name]** in the list of [add-ins/scripts]. [if add-in, You may want to check the 'Run on startup' option so it automatically runs when Fusion starts., otherwise remove this line] Click the **Run** icon to execute the [add-in/script].

#### Option 2: Install in a Custom Directory
1. **Download:** Download the source code as a ZIP file and extract the `[add-in/script]` folder. Rename the folder to `[add-in/script name]`.
2. **Organize:** Create a dedicated folder on your computer for your Fusion tools (e.g., `Documents\Fusion_Tools`) and move the `[add-in/script name]` folder inside it (remove the `-main` suffix) — Fusion requires the folder name to match the add-in name exactly, so it won't run correctly if you skip this step.
3. **Open Fusion:** Press `Shift + S` to open the **Scripts and Add-Ins** dialog.
4. **Add the Add-in:** Click the grey **"+"** icon next to the search box at the top of the dialog and select **Script or add-in from device**.
5. **Locate:** Navigate to your custom folder, select the `[add-in/script name]` folder, and click **Select Folder**.
6. **Run the [Add-in/Script]:** Make sure the **[Add-ins/Scripts]** filter checkbox is checked. You should see **[add-in/script name]** in the list of [add-ins/scripts]. [if add-in, You may want to check the 'Run on startup' option so it automatically runs when Fusion starts., otherwise remove this line] Click the **Run** icon to execute the [add-in/script].
