---

## Introduction

Fusion API Template Forge is a standalone, purely client-side web application that generates ready-to-code Fusion add-in and script project folders as a downloadable zip. Pick the features you want &mdash; a persistent HTML palette UI, Theme Designer Pro support, a config/preset manager, and more &mdash; fill in your add-in's name, and download a project folder you can drop straight into Fusion's Scripts and Add-Ins loader.

It fixes the gaps left by Fusion's own "Create Add-in"/"Create Script" scaffolding (no manifest `id` GUID, empty `description`, no version, etc.) and bakes in the structural conventions used across Ed's Fusion add-in fleet.

## Features

* **Zero Dependencies to Run:** Pure HTML, CSS, and Vanilla JavaScript. No servers, no build steps, no accounts.
* **Pick Your Starting Point:** Bare script, bare add-in, add-in + persistent HTML palette, or add-in + palette + full Theme Designer Pro theming support.
* **Fusion Gaps, Fixed:** Generates a real manifest `id` GUID, a non-empty description, and a proper version string wired to a single source of truth.
